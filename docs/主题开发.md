# 主题开发

WorkerBBS 支持「上传 zip 主题包」一键换肤。主题本质是一段 CSS，通过覆盖站点的**语义 CSS 变量**改变配色与外观，无需改动任何源码、也不进代码仓库（运行时存进 D1）。

## 一、安装方式

1. 以管理员身份进入后台 `/admin` → 左侧「主题」面板。
2. 点击「选择主题包」，选中一个 `.zip` 文件，点「安装并应用」。
3. 全站（含深色模式）立即生效。后台会显示「当前主题：<主题名>」。
4. 点「卸载（恢复默认）」即可清空，恢复默认外观。

> 主题只覆盖变量，**不会**替换页面结构或逻辑。

## 二、主题包结构

一个合法的 `.zip` 至少包含：

| 文件 | 必填 | 说明 |
|---|---|---|
| `theme.css` | ✅ 必需 | 主题样式，覆盖语义变量即可换肤 |
| `info.json` | 可选 | 元信息：`{ "name": "主题名", "author": "作者", "version": "1.0.0" }` |

`theme.css` 可以放在 zip 根目录，也可以放在任意子目录（安装时会自动查找名为 `theme.css` / `*.css` 的文件）。`info.json` 同理。

**大小限制**：`theme.css` 解压后建议 < 600KB（存进 D1 单值有上限）。

## 三、theme.css 写法

主题通过覆盖以下语义变量工作。只写你需要改的变量即可，未覆盖的沿用默认。

### 浅色模式变量（`:root`）

```css
:root {
  --accent: #0f6cbd;     /* 强调色：按钮、链接、选中态 */
  --text: #1b1b1b;       /* 主文字 */
  --text-2: #767676;     /* 次要文字（时间、说明） */
  --bg: #ffffff;         /* 页面背景 */
  --surface: #ffffff;    /* 卡片 / 浮层背景 */
  --surface-2: #f6f6f6;  /* 次级背景（输入框、表头） */
  --border: #ebebeb;     /* 边框 / 分隔线 */
  --hover: #efefef;      /* 悬停背景 */
}
```

### 深色模式变量（`[data-theme="dark"]`）

深色切换由 `data-theme="dark"` 控制，因此深色变量必须写在该选择器下：

```css
[data-theme="dark"] {
  --accent: #4aa3ff;
  --text: #f3f3f3;
  --text-2: #9aa0a6;
  --bg: #161616;
  --surface: #1e1e1e;
  --surface-2: #262626;
  --border: #2c2c2c;
  --hover: #2a2a2a;
}
```

> ⚠️ 注意：如果你只在 `:root` 写死 `--bg`，深色模式切换时背景不会变。浅色 / 深色请**分开声明**。

## 四、完整示例

`my-theme.zip` 内容：

`theme.css`：
```css
:root {
  --accent: #e0533d;
  --bg: #fbf7f2;
  --surface: #ffffff;
  --border: #ecdcd2;
}
[data-theme="dark"] {
  --accent: #ff7a5c;
  --bg: #1a1411;
  --surface: #241c18;
  --border: #3a2c25;
}
```

`info.json`：
```json
{
  "name": "暖橙",
  "author": "your-name",
  "version": "1.0.0"
}
```

打包（`theme.css` 与 `info.json` 放根目录）后上传即可。

## 五、卸载

后台「主题」面板 →「卸载（恢复默认）」，会清空存储的主题 CSS，全站恢复默认外观。

## 六、注意事项

- 主题优先级最高：注入的 `<style id="user-theme">` 位于 `<head>` 末尾，会覆盖默认 `:root` 变量。若想进一步微调（如改圆角、阴影），可直接在 `theme.css` 写具体选择器。
- 主题对所有访客生效（包括未登录用户），是**站点级**外观，不是个人偏好。
- 个人深色 / 浅色切换是单独的用户偏好（`localStorage`），与主题叠加生效。
- 变量命名以 `--` 语义变量为准，不要直接改 `#bg`、`.post-card` 等具体规则，否则跨版本易失效。
