发信配置（Resend）

发件人将显示为：前缀@域名

说明

1. 在 resend.com 注册并创建 API 密钥。
2. 填写密钥后点「查看所有可用域」，系统会列出你在 Resend 已验证的域名。
3. 选择一个域名并填写前缀（如 no-reply），发件人即为 no-reply@你的域名。
4. 勾选「启用注册邮箱验证」后，新用户注册会收到验证邮件，点击邮件里的链接才能完成验证并登录。

实时同步（WebSocket 节点）

节点需作为独立 Worker 单独部署（见仓库 ws/ 目录）。部署后把节点地址填到「WebSocket 端点」即可，发帖 / 回复 / 点赞 / 关注等事件会实时推送给在线用户。无需密钥。
