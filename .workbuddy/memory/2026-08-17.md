## Bug 修复：提示被卡片盖住 + 缺帖子详情页
- 用户反馈：① 悬停图标提示被帖子卡片盖住；② 点帖子无详情页。
- 根因①：`.rail` 为 `position:fixed` 未设 z-index，而 `.post-card` 有 transform 动画会创建独立层叠上下文，按 DOM 顺序画在 rail 之后，盖住 tooltip。修复：给 `.rail` 加 `z-index:100`。
- 补 `viewPost(id)`：详情页（标题/正文/作者/回复列表/回复框）；卡片点击用 `content.addEventListener('click', ...)` 委托，匹配 `.post-card` → 进详情；详情页"← 返回"回到来源视图（returnTo：home/search/profile 各自记录）。回复框发送会用 `insertAdjacentHTML` 追加并刷新计数（仅前端 Demo，不落库）。
- 注意：在 Python 三引号字符串里写 JS 的 `\n` 要写成 `\\n`，否则 Python 会把 `\n` 转成真实换行破坏 JS 字符串字面量。
- 强调色选择器会改 `:root --accent`，图标/选中条/按钮/卡片标签随之联动。尊重 `prefers-reduced-motion`。改后跑 `python build_index.py` 重新生成。

## 图标大小不一（已修）
- 用户反馈左侧栏图标"大小不一/诡异"。根因：Fluent 线性(Regular)图标的字形在 24 网格里占格不同（汉堡 20×14.5、person 16×20、其余 17–19），塞进同一 20px 框就显得大小不一 —— 不是渲染像素问题，是光学尺寸不一致。
- 修法：`build_index.py` 加 `normalize()` 做**光学归一化**——内联时解析每个 path 的 bbox，按最大边 `scale=TARGET/max(w,h)`（TARGET=18）缩放到统一尺寸并居中到 (12,12)，同时去除 svg 上的 width/height 让 CSS 全权控制 20px。
- 验证：归一化后 6 个图标 max 维度全部 = 18.00、几何中心均落在 (12,12)。改图标后重新跑 `python build_index.py` 即可。
